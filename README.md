# Childcare SaaS Platform

Production-focused B2B childcare operations platform for owners, operators, and CEOs.

## Active App
- `apps/web` - Next.js app (App Router)

## Infrastructure
- `infra/supabase` - SQL schema, RLS, seeds
- `infra/stripe` - products/pricing/webhook notes
- `infra/vercel` - deployment notes

## Legacy Files
- `legacy-prototypes` - archive for old prototype/landing assets

## Stack
- Next.js
- Supabase (Auth, Postgres, Storage)
- Stripe
- Resend
- PostHog
- Vercel
